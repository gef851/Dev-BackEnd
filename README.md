## 🎯 Objetivo da API

Esta API foi desenvolvida com o objetivo de fornecer serviços de integração e comunicação entre sistemas, permitindo o gerenciamento e consumo de dados por meio de endpoints REST.
 
A aplicação foi construída utilizando Node.js e Express, seguindo boas práticas de desenvolvimento, organização de código e versionamento.
